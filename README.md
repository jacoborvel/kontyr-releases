# kontyr-releases

Releases oficiales de la app de escritorio Kontyr (macOS Apple Silicon, Windows MSI y EXE), cada una con sus checksums SHA-256 y, desde 1.0.2, los artefactos firmados del updater (`.app.tar.gz` y `.sig`) que consume el feed `https://kontyr.co/desktop/updates/{target}.json`.

Las releases son append-only. Osnova y TwinTown son marcas retiradas: sus binarios se retiraron de `desktop-v1.0.1` el 2026-09-13 y no se publican más.
